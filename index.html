Red
To Green

When a CI build fails, RedToGreen reads the error, writes a fix and runs the tests in a sandbox. It keeps going until the build passes or it runs out of budget.

GitHub sends a signed webhook, Caddy checks it, and a worker picks up the job. Every step has a hard limit, so the agent can't loop forever. If a worker crashes mid-job, a watchdog takes the job back after 45 minutes.

  • Python
  • LLM agent
  • GitHub webhooks
  • Sandboxed tests
  • Caddy

Document
Intelligence

Ask a question and get an answer taken from your own documents, along with the exact passages it used.

Django and FastAPI on the backend, React on the front. JWT sign-in and role-based access decide which documents each person can search. A LangGraph pipeline of agents finds the right passages in ChromaDB, and Groq writes the answer from them.

URL
Shortener

A link shortener I rewrote for speed, then load-tested to prove the rewrite worked.

FastAPI with Redis in front of PostgreSQL and collision-resistant short codes. It keeps no state on the server, so it scales by adding instances. Tested with k6: redirects went from 492 ms to 256 ms, and throughput from 203 to 424 requests a second.
